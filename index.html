Setup Google Cloud — guida completa
Questa guida configura l'integrazione Google in modo che l'app possa leggere e scrivere automaticamente su Google Sheets (dati finanziari) e Google Drive (PDF fatture). Una volta configurato, tutto è sincronizzato in tempo reale su tutti i tuoi dispositivi.
Prerequisito: l'app deve essere servita da un dominio HTTPS — GitHub Pages la rende disponibile su https://tuonome.github.io/finanze-piva, che è perfetto. OAuth Google non funziona su file:// né su http://.
1
Crea il repository GitHub e attiva GitHub Pages
Vai su github.com/new e crea un repository pubblico chiamato finanze-piva.
Carica i file dell'app (index.html, manifest.json).
Vai su Settings → Pages → Source: Deploy from branch → main → / (root).
Dopo 1-2 minuti l'app è live su https://tuonome.github.io/finanze-piva.
2
Crea un progetto su Google Cloud Console
Vai su console.cloud.google.com.
Clicca sul selettore progetti in alto → Nuovo progetto → nome FinanzePIVA → Crea.
3
Abilita le tre API necessarie
Vai su API e servizi → Libreria. Cerca e abilita:
— Google Sheets API — per leggere e scrivere i dati finanziari
— Google Drive API — per archiviare i PDF delle fatture
— Google Picker API — per selezionare file da Drive (opzionale)
4
Configura la schermata di consenso OAuth
Vai su API e servizi → Schermata consenso OAuth.
Tipo utente: Esterno → Crea.
Compila: nome app Finanze PIVA, email supporto (la tua).
Nella sezione Ambiti aggiungi:
— .../auth/spreadsheets — lettura/scrittura Sheets
— .../auth/drive.file — accesso solo ai file creati dall'app
Nella sezione Utenti di test aggiungi la tua email Google.
Nota: finché l'app è in modalità "test" funziona solo per gli utenti aggiunti qui.
5
Crea le credenziali OAuth 2.0
Vai su API e servizi → Credenziali → Crea credenziali → ID client OAuth.
Tipo applicazione: Applicazione web.
Nome: Finanze PIVA Web.
In "Origini JavaScript autorizzate" aggiungi esattamente:
https://tuonome.github.io
(sostituisci tuonome con il tuo username GitHub)
In "URI di reindirizzamento autorizzati" aggiungi:
https://tuonome.github.io/finanze-piva
Clicca Crea. Copia il Client ID che appare.
6
Incolla il Client ID nell'app e accedi
Vai su Impostazioni → Google → Google Client ID e incolla il codice copiato (formato: 123456789-abc...apps.googleusercontent.com).
Clicca Sincronizza ora oppure ricarica la pagina e accedi con Google.
L'app creerà automaticamente:
— Google Sheet Finanze PIVA con 7 fogli strutturati
— Cartella Drive Finanze PIVA / Fatture per i PDF
7
Come funziona la sincronizzazione
Ogni volta che aggiungi un incasso, una rata INPS, un conto o un movimento, i dati vengono salvati in tempo reale sul tuo Google Sheet.
Ogni PDF che carichi viene salvato nella cartella Drive e il link viene memorizzato nello Sheet.
Aprendo l'app da telefono, tablet o altro PC troverai tutto sincronizzato.
Puoi anche aprire il Google Sheet direttamente da Drive per vedere i dati in formato tabella e fare analisi aggiuntive.
Tip sicurezza: l'ambito drive.file permette all'app di accedere solo ai file che essa stessa crea — non all'intero Drive. I tuoi altri file rimangono privati e non accessibili dall'app.
